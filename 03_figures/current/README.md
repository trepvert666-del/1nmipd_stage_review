## NEW-01 测量实体与图案坐标形成

[测量实体与图案坐标形成](fig01_测量实体与坐标形成.svg)

限制：未冻结光机安装尺寸、坐标轴符号接口及具体校正算子。；Cₖ包含尺度、方向和畸变映射，原始像素不与长度直接相加。；ESC的Z形貌须映射为XY影响，不直接相减；补偿残余不预设为零。

## NEW-07 Step-and-Measure的真实动作顺序与时间边界

[Step-and-Measure的真实动作顺序与时间边界](fig07_step_measure_timing.svg)

用途：XY稳定150 ms、按策略AF100 ms、曝光采集30 ms按比例绘制；运动、未包含的恢复等待和读出另计；干涉计量持续并行；280 ms只是执行AF帧的已知串行三段设计分配下限，并非已实现周期；原AF方案约0.4–2.5 s/点，与100 ms当前设计分配尚待对账

属性：当前工程时间分配；未知时长用虚线和断轴表示，非样机时间记录。AF100 ms尚未与原方案0.4–2.5 s/点的核算闭合。

限制：未知段图宽无时间含义；逐FOV AF策略、失败重试与可重叠时间未冻结；100 ms是当前基线的AF设计分配，不是已验证AF时间；280 ms不是完整帧周期，也不是未执行AF帧的统一时长，更不能表述为已经实现的周期

# 1 nm级晶圆IPD量测设备整机证据树

> 版本：v0.1
>
> 日期：2026-09-18
>
> 状态：内部论证基线
>
> 对应预算：补偿后二维综合位置残差 \(3\sigma_{XY}\le1\ \mathrm{nm}\)

## 1 文件目的

本文件用于回答两个问题：

1. 整机1 nm量测目标中的每一个关键判断需要什么证据；
2. 现有公开资料、理论计算、工程分配和后续试验分别能够证明到什么程度。

证据树不把设计目标改写为已有能力，也不通过拼接不同设备、不同负载和不同统计条件下的最佳参数证明整机可行。每一条证据必须保留对象、环境、负载、行程、带宽、时间窗口、统计口径和适用边界。

## 2 顶层主张

顶层主张C0定义为：

> 在规定图案、照明、焦位、装夹、温度、测量路径、曝光窗口、标定版本和算法版本下，设备对TSV或规定计量标记位置进行标定与系统误差补偿后，二维综合位置残差满足：

\[
3\sigma_{XY}
=3\sqrt{\sigma_{x,\mathrm{res}}^2+\sigma_{y,\mathrm{res}}^2}
\le1\ \mathrm{nm}.
\]

顶层主张成立需要同时闭合以下四条证据链：

```text
C0-1 被测量与统计口径明确
C0-2 图像坐标和工作点坐标可溯源地融合
C0-3 七项补偿后残差及协方差满足整机预算
C0-4 完整流程的环外验证满足1 nm目标
```

其中，C0-1至C0-3可以通过公开证据、理论计算、设计分析、仿真和子系统测试逐步建立；C0-4只能由规定条件下的整机样机试验最终证明。当前项目阶段最多形成C0的设计可行性证据，不能写成已完成整机实测验收。

## 3 证据分类与结论强度

### 3.1 证据来源类型

| 代码 | 证据类型 | 主要用途 |
|---|---|---|
| P | 物理模型与理论推导 | 建立传递关系、尺度关系和不可违反的边界 |
| L | 论文、标准和计量机构资料 | 证明方法、量级及统计方法已有公开基础 |
| A | 专利和成熟设备架构 | 证明工程路线、结构或控制方法已经公开 |
| S | 供应商正式规格与应用资料 | 证明候选部件在规定条件下的公开能力 |
| C | 本项目计算、仿真和误差传播 | 将外部证据换算到本项目条件 |
| T | 样件、子系统和整机试验 | 证明本项目实际达到的性能 |

### 3.2 结论强度

| 等级 | 定义 |
|---|---|
| A | 在与本项目相同或可比条件下有直接公开证据或本项目实测证明 |
| B | 有可靠公开证据和明确物理换算，量级可支持，但条件尚不完全一致 |
| C | 工程上合理，主要依赖设计分配、理论推导或间接证据 |
| D | 证据不足，尚不能支持当前数值或表述 |

项目书中的结论不得超过证据树记录的结论强度。A级和B级可用于论证技术可行性；C级必须写明实现条件；D级只能作为假设、风险或验证任务。

## 4 整机一级证据树

### 4.1 E1 图像与TSV中心定位残差

**预算主张：**

\[
B_{\mathrm{image}}\le0.55\ \mathrm{nm}
\]

**必须证明：**

1. 规定物方采样、SNR和曝光条件下，随机成像噪声的二维3σ贡献不超过0.25 nm；
2. 中心估计算法的重复性和数值残差不超过0.25 nm；
3. 真实TSV圆度、边缘粗糙度、缺陷和灰度非对称造成的中心定义残差不超过0.42 nm；
4. TSV位置被测量固定为规定成像与处理条件下的最佳拟合对称中心，不因算法更换改变物理定义。

**证据组合：**

- L：亚像素定位、对称标记定位和Cramér–Rao下界资料；
- C：像元、倍率、SNR、边缘点数和物方定位误差换算；
- T：标准圆形标记、真实TSV样品、缺陷样品和重复曝光试验；
- T：不同算法对同一批TSV的中心偏差与稳定性比较。

**当前判断：** 纯图像中心定位达到亚纳米量级已有公开依据，结论强度暂为B；真实TSV中心模型稳定性缺少直接样品证据，暂为C。

### 4.2 E2 运动平台与位置计量残差

**预算主张：**

\[
B_{\mathrm{stage+metrology}}\le0.55\ \mathrm{nm}
\]

**必须证明：**

1. 干涉仪数字分辨率、非线性、电子学噪声和整机读数稳定性经标定后的贡献不超过0.29 nm；
2. 曝光窗口内Wafer—Lens有效相对运动贡献不超过0.28 nm；
3. Measurement Ready触发后的尾振和低频残差不超过0.24 nm；
4. 干涉光路快速环境扰动贡献不超过0.22 nm；
5. 相机曝光和干涉采样时间配准贡献不超过0.17 nm。

**证据组合：**

- S/L：干涉计量非线性、稳定性、空气光程与环境补偿资料；
- P/C：曝光积分、时间误差、残余速度和位置误差传播；
- C/T：粗动扰动到最终工作点的闭环传递函数、PSD、Bode、链路延迟和幅相匹配；
- T：带载停稳、不同路径、不同位置和曝光窗口内的环外相对运动测量。

**当前判断：** 亚纳米干涉计量和纳米级平台稳定性分别存在公开基础，暂为B；400 mm行程、重载ESC和整机光路条件下的联合残差只能由本项目集成试验证明，暂为C。

### 4.3 E3 光学映射补偿残差

**预算主张：**

\[
B_{\mathrm{optical}}\le0.35\ \mathrm{nm}
\]

**必须证明：**

1. 200 µm有效FOV内几何畸变Map补偿后的二维3σ残差不超过0.20 nm；
2. 物方倍率和局部尺度标定残差不超过0.15 nm；
3. PSF、像差和照明非对称引起的图像偏移残差不超过0.17 nm；
4. 相机像素网格标定残差不超过0.12 nm；
5. 光学内部状态和成像模式切换重复性残差不超过0.12 nm。

**证据组合：**

- L/S：193/194 nm显微光学、物镜NA、畸变、像差和探测器资料；
- P/C：倍率、像元、FOV、PSF宽度与定位敏感度计算；
- T：可溯源二维标定板多视场位置扫描、畸变Map拟合和交叉验证；
- T：标记旋转、照明方向变化和成像状态切换试验，用于分离样品非对称与光学TIS。

**当前判断：** 194 nm成像和亚像素定位原理具备公开基础，但0.35 nm是补偿后映射残差，不等于物镜目录畸变指标；在获得标定板和稳定性数据前暂为C。

### 4.4 E4 ESC、装夹与面形补偿残差

**预算主张：**

\[
B_{\mathrm{ESC}}\le0.35\ \mathrm{nm}
\]

**必须证明：**

1. 同一装夹状态的面形和图案坐标指纹可以稳定复现并建立补偿Map；
2. 重复装夹、吸附电压、温控流量和晶圆背面状态变化后的不可重复残差满足预算；
3. 晶圆相对计量镜的未观测变形不会被干涉仪终端读数错误地视为零；
4. 装夹引起的整体平移、旋转与局部高阶变形分开处理，不与全局坐标标定重复计数。

**证据组合：**

- L/A：ESC夹持、晶圆形貌和重复装夹相关论文与设备架构；
- P/C：夹持力、晶圆弯曲、面形斜率到图案XY坐标的传递模型；
- T：多次卸片重装、不同吸附参数和温控状态下的图案坐标指纹；
- T：面形测量与图案坐标残差的相关性和补偿交叉验证。

**当前判断：** 该项的原理证据可建立，但0.35 nm主要受run-to-run不可重复性限制，当前暂为C，是证据树中的高风险分支。

### 4.5 E5 温度与慢环境补偿残差

**预算主张：**

\[
B_{\mathrm{thermal}}\le0.25\ \mathrm{nm}
\]

**必须证明：**

1. Wafer、ESC、平台、计量框、物镜和参考结构的温度灵敏度可以测量并建模；
2. 空间温度梯度、热滞后和热源工作周期不会被单点温度值替代；
3. 温度、气压和湿度的慢变化经补偿后的坐标残差满足预算；
4. 快速空气光程扰动归入运动与干涉计量项，不在本项重复计算。

**证据组合：**

- P/L：材料热膨胀、空气折射率和热时间常数模型；
- C：热源清单、热网络、结构灵敏度和坐标漂移计算；
- T：热浸、升降温、稳定保持和不同工况循环试验；
- T：温度场到坐标残差的模型训练、冻结和独立工况验证。

**当前判断：** 热漂机理和补偿方法有充分公开基础，但0.25 nm对温度场观测和模型稳定性要求很高，在整机热试验前暂为C，是高风险分支。

### 4.6 E6 全局坐标与溯源标定残差

**预算主张：**

\[
B_{\mathrm{global-cal}}\le0.25\ \mathrm{nm}
\]

**必须证明：**

1. 图像局部坐标、干涉仪工作点坐标和Wafer全局坐标之间的尺度、旋转、正交性和原点关系可标定；
2. 姿态、阿贝臂、镜面形貌和全行程几何误差经校正后的残差满足预算；
3. 参考标定板或Golden wafer的坐标能够溯源，其校准不确定度和传递误差被单独报告；
4. 光学局部倍率归光学映射项，全行程坐标尺度和参考传递归本项，不重复计数。

**证据组合：**

- L/S：二维计量标准、激光干涉坐标计量和校准方法；
- P/C：姿态、阿贝、镜面局部斜率和坐标变换误差传播；
- T：可溯源二维标准器的多位置、多方向和重复安装测量；
- T：全行程几何Map、交叉验证和不同标定周期之间的漂移检查。

**当前判断：** 坐标标定方法已有成熟基础，但0.25 nm同时受标准器、全行程几何和坐标传递影响，当前暂为C，是整机验收能否成立的关键分支。

### 4.7 E7 Z、自动对焦及XY耦合残差

**预算主张：**

\[
B_{\mathrm{Z/AF}}\le0.15\ \mathrm{nm}
\]

**必须证明：**

1. Sony类狭缝AF在规定表面、照明和反射率条件下的焦位偏差与重复性；
2. 焦位误差通过telecentric、倍率、像差和物镜运动耦合到XY坐标的灵敏度；
3. AF态切换到成像态后的焦位与横向像移重复性；
4. Focus Ready判据能够保证采图时焦位位于标定有效窗口内。

**证据组合：**

- L/A：狭缝式AF原理、专利和成熟设备结构；
- P/C：\(\Delta x=K_{xz}\Delta z\)、\(\Delta y=K_{yz}\Delta z\)及允许焦位窗口计算；
- T：Z扫描标定、不同FOV位置和不同TSV表面状态下的XY—Z灵敏度；
- T：AF/成像切态、重复对焦和长时间运行试验。

**当前判断：** AF技术路线成熟，但0.15 nm是折算到XY后的残差，不是AF自身Z重复性；在获得本光学系统的XY—Z实测灵敏度前暂为C。

## 5 交叉证据与预算闭合

七项一级预算按独立近似得到：

\[
\sqrt{0.55^2+0.55^2+0.35^2+0.35^2+0.25^2+0.25^2+0.15^2}
\approx0.999\ \mathrm{nm}.
\]

该计算只能证明数值分配闭合，不能证明整机能力。证据树还必须覆盖以下交叉问题：

| 交叉问题 | 处理原则 |
|---|---|
| 相关性和协方差 | 光学倍率与全局尺度、ESC状态与温漂、空气光程与温湿度等相关项必须用协方差或联合试验处理 |
| 重复计数 | 每个物理误差只归属一个一级预算项；控制、前馈和补偿方法不作为新的误差源再次相加 |
| 未建模残差 | 通过整机环外残差和多工况交叉验证暴露，不预先虚构额外预算值 |
| 参考标准不确定度 | 纳入全局坐标和溯源链，并在最终测量不确定度中报告；不把标准器目录分辨率直接等同于坐标真值 |
| 样本量与保护系数 | 规定样本数、置信水平、异常值和失败帧规则；小样本3σ不得直接视为总体能力 |
| 最差工况 | 覆盖FOV位置、Wafer位置、运动方向、重装夹、温度状态和时间跨度，不只报告中心点最佳结果 |

## 6 不进入单次1 nm预算的对象

以下对象需要各自的证据链，但不进入最终状态单次图案位置量测的1 nm RSS预算：

- 25个实测Die到未测Die的高阶场预测误差；
- Die内稀疏采样替代全量TSV测量的重建误差；
- Pre/Post差分中的两次注册、跨时间漂移和跨工艺图形变化；
- IPD到Bonding Overlay、界面质量或结合强度的推断误差；
- IPD到CPE参数、曝光后Overlay改善量的模型和接口误差。

这些对象分别属于高级分析、可选差分或下游应用验证，不得反向改变设备1 nm直接量测能力的定义。

## 7 当前证据优先级

后续证据检索和计算按下列顺序推进：

1. **E6全局坐标与溯源标定**：决定1 nm结果能否具有坐标意义和验收依据；
2. **E4 ESC与重复装夹**：公开直接数据少，且run-to-run变化难以通过静态Map完全消除；
3. **E5温度与慢环境补偿**：0.25 nm预算对空间温度场和模型稳定性要求高；
4. **E3光学映射**：需要证明0.35 nm是标定后映射残差，而不是名义分辨率；
5. **E2运动与计量**：已有部分公开量级依据，重点转向整机集成条件；
6. **E1图像定位**：已有亚像素公开依据，重点转向真实TSV样品；
7. **E7 Z/AF耦合**：技术路线明确，关键是实测XY—Z灵敏度。

每个分支完成后，输出统一包含：主张、物理机制、误差模型、原始证据、条件换算、本项目预算对比、结论强度、剩余风险和验证方法。若高可信证据与当前预算冲突，按“现有预算—冲突证据—影响—建议调整”记录，不直接静默修改基线。

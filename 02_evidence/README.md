# 证据树文件导航

建议按以下顺序阅读：

1. [整机1nm证据树](整机1nm证据树.md)：顶层被测量、一级证据树、E1—E7映射、缺口与冲突；
2. [一级证据源清单与主张摘录](一级证据源清单与主张摘录.md)：5份一级文件的版本、hash、数值主张和下钻节点；
3. [系统证据闭环与验证矩阵](系统证据闭环与验证矩阵.md)：把主张转换为试验、数据和交付物；
4. [下级证据索引](下级证据索引.md)：标准、论文、专利和供应商原始资料的回查入口；
5. E1—E7文件：按误差预算科目查看现有证据、边界与待验证项。

## 层级约定

- L1-OA、L1-AF、L1-ST、L1-VIB、L1-OENV：本轮一级证据文件；
- E1—E7：系统误差预算科目，不是证据级别；
- EXT：标准、论文、专利和供应商等下级证据；
- SYS/IMG/ZAF/MOT/ENV/ESC：验证任务编号；
- CFL：一级证据之间的冲突；
- G：已有下级证据尚待用试验数据或接口冻结闭合的节点。

## 当前结论

现有5份一级资料覆盖光学算法、AF、机台、振动稳定和其他环境；ESC、温湿压、坐标融合/标准样件及整机验证已经有此前讨论或专项文档，按本项目约定挂接为二级及以下证据，不再误判为“未讨论”或要求另增一级分册。当前真正尚未闭合的是统一接口版本、本机原始试验数据、补偿后定量残差及端到端不确定度。因此证据树已能形成完整设计论证，但仍不能形成“已达到1 nm”的验收结论。
